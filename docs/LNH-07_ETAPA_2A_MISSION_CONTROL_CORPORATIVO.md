# LNH-07 Etapa 2A Mission Control Corporativo

Mission Control presenta la jerarquía Mi Oficina, Holding, Empresas, Pisos, Gerentes y Agentes. Reutiliza el Case Manager y el backend existente de MGC-05; no modifica perfiles profesionales ni proveedores de inferencia.

MGC-05 se muestra como Operativo dentro de su alcance actual. MGC-03 se muestra como En construcción: su gerente puede registrar una misión y un plan inicial, pero no existe todavía ejecución E2E de AGIA-MGC-007, consolidado MGC-03 ni Human Gate ejecutable para ese piso.

Los documentos son opcionales al enviar una misión. Cuando se adjuntan, se conservan en el expediente con hash. La ruta Fuente, Evidencia, Hallazgo y Output muestra únicamente los registros materializados; los elementos no producidos permanecen como No disponible o Pendiente de implementación.
