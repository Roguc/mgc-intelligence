# LNH-07 — Etapa 2: Primer Piso Funcional MGC-05

FloorManager interpreta la misión usando capacidades del AgentRegistry, construye un plan ordenado y registra dependencias. El backend conserva los agentes existentes como ejecutores registrados.

El Handoff Registry conserva origen, destino, evidencia y motivo; el Contradiction Checker aplica la regla conservadora; el consolidado mantiene atribución profesional y deriva decisiones hacia Human Gate. Las pruebas usan mocks y fixtures, sin inferencia real, Vast ni GPU.
